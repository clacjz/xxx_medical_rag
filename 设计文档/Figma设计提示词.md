## 项目概述

设计一个**企业级医学知识库智能问答系统**的前端界面。系统基于 RAG（检索增强生成）技术，为医疗从业者提供智能文档检索和问答服务。

## 设计风格

### 整体风格
- **风格定位**：专业、简洁、高效的企业级 SaaS 风格
- **设计语言**：参考 Ant Design Pro / Element Plus Admin
- **界面特点**：清晰的层级结构、充足的留白、直观的操作流程

## 核心页面设计

### 1. 登录/注册页

**设计要点**：
- 渐变背景：左侧 2/3 为品牌渐变 (#667eea → #764ba2)
- 右侧 1/3 为白色登录表单卡片
- 登录框居中，圆角 12px，阴影深度适中
- 输入框使用 Element Plus 原生样式
- 品牌 Logo 和标语居中展示

**元素清单**：
- Logo (64x64)
- 系统名称 (H1)
- 副标题 (Body, 颜色: #909399)
- 用户名输入框 (带图标)
- 密码输入框 (带图标、可切换显示)
- 登录按钮 (Primary, 100%宽度, 高度48px)
- "忘记密码" 链接
- 注册入口 (底部)

### 2. 仪表盘 (Dashboard)

**设计要点**：
- 顶部 4 个统计卡片横向排列
- 使用图标 + 数字 + 标签的组合
- 每个卡片有悬浮阴影效果

**元素清单**：
- 统计卡片 x4: 知识库数、文档总数、问答次数、用户数量
- 系统健康状态卡片: PostgreSQL、Redis、Qdrant、MinIO 状态指示
- 最近文档处理列表
- 快速入口按钮组: 知识库管理、文档上传、智能问答、对话历史

### 3. 知识库管理页

**设计要点**：
- 顶部工具栏：搜索框 + 筛选 + 新建按钮
- 表格展示知识库列表
- 支持分页、排序操作
- 行内操作按钮（详情、编辑、删除）

**元素清单**：
- 页面标题 + 新建按钮
- 搜索框、状态筛选下拉、刷新按钮
- 数据表格: 名称、描述、文档数、分块数、Embedding模型、状态、创建时间、操作
- 创建/编辑知识库弹窗表单

### 4. 文档管理页

**设计要点**：
- 文件上传区域使用拖拽样式
- 表格显示文档状态和进度
- 支持批量操作
- 状态以彩色标签+进度环展示

**元素清单**：
- 页面标题 + 上传按钮
- 知识库筛选、状态筛选、搜索框、刷新按钮
- 数据表格: 复选框、文档名称、类型、大小、状态(含进度环)、所属知识库、分块数、上传时间、操作
- 上传弹窗: 拖拽上传区、文件列表、上传进度

### 5. 智能问答页 (核心页面)

**设计要点**：
- 左侧对话列表面板（可折叠）
- 右侧主对话区域
- 底部输入框固定
- AI 回复使用特殊的样式区分

**布局设计**：
- 左侧对话列表: 新建按钮、会话列表(标题、消息数)、会话操作菜单
- 右侧主区域: 知识库选择器、对话消息区、AI回复卡片(含引用来源展开)、输入框
- AI 回复卡片包含: 回复内容、引用来源列表(文档名+相似度)

### 6. 用户管理页

**设计要点**：
- 表格展示用户列表
- 角色以彩色标签区分
- 支持筛选（角色、状态）

**元素清单**：
- 页面标题 + 添加用户按钮
- 搜索框、角色筛选、状态筛选、刷新按钮
- 数据表格: 用户名、邮箱、角色(彩色标签)、状态、创建时间、操作
- 添加/编辑用户弹窗表单

## 附加说明

### 技术栈背景
- **后端**: Spring Boot 3.x + Spring AI Alibaba
- **前端框架**: Vue 3 + TypeScript + Element Plus
- **AI服务**: Ollama/vLLM (本地部署)
- **向量数据库**: Qdrant

### 目标用户
- 知识管理员：知识库配置和维护
- 普通用户：文档上传、智能问答、知识浏览
- 系统管理员：系统配置和用户管理

### 核心功能模块
1. 用户认证与权限管理 (JWT + RBAC)
2. 知识库管理 (CRUD + 配置)
3. 文档处理 (上传、解析、分块、向量化)
4. 智能问答 (RAG 检索增强生成)
5. 对话管理 (多轮对话上下文)
6. 审计日志 (操作记录追溯)
